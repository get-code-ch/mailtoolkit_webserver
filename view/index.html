Analyse de mail

Vous avez reçu un mail suspect ? Transférez-le à une adresse temporaire pour l'examiner sans risque : son contenu est affiché sans exécuter de code et sans charger d'images distantes.

Comment faire

  1. Cliquez sur « Nouvelle analyse » : une adresse aléatoire et une page privée sont créées.
  2. Transférez le mail suspect en tant que pièce jointe à cette adresse (un simple transfert modifie le mail original et fausse l'analyse).
  3. Le mail apparaît sur votre page privée après quelques secondes.

Transférer un mail en pièce jointe
  • Gmail : ouvrez le mail, menu « ⋮ » puis « Transférer en tant que pièce jointe ».
  • Outlook : menu « … » du mail, « Transférer » puis « Transférer en tant que pièce jointe ». Depuis Outlook pour Windows : Ctrl+Alt+F.
  • Thunderbird : clic droit sur le mail, « Transférer en tant que » puis « Pièce jointe ».
  • Apple Mail : menu « Message » puis « Transférer en tant que pièce jointe ».
  • Vous pouvez aussi joindre un fichier .eml ou .msg enregistré depuis votre messagerie.
