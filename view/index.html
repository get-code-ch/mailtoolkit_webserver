Envoyer le mail sans le modifier : mode d'emploi par messagerie

Le mail doit arriver intact, comme pièce jointe ou comme fichier. Un transfert ordinaire (« Transférer ») recopie le texte dans un nouveau mail : les en-têtes et les signatures d'origine sont perdus. Les applications mobiles ne proposent en général aucune de ces options : utilisez la version web ou l'application de bureau.

Proton Mail
Pas de transfert en pièce jointe. Ouvrez le mail, menu ⋮ (Plus) en haut du message, puis « Télécharger » ou « Exporter » : un fichier .eml est enregistré. Déposez-le ensuite ici.
Gmail (web)
Dans la liste des mails, clic droit sur le mail puis « Transférer en tant que pièce jointe ». Ou, mail ouvert : menu ⋮ à droite de la flèche de réponse, puis « Télécharger le message » pour obtenir le fichier .eml.
Outlook (web, nouveau Outlook)
Mail ouvert, menu … (Autres actions) puis « Transférer » › « Transférer en tant que pièce jointe ». Selon la version, l'option se trouve aussi dans la flèche à côté du bouton « Transférer » du ruban.
Outlook classique (Windows)
Sélectionnez le mail puis Ctrl+Alt+F. Ou glissez le mail sur le bureau : vous obtenez un fichier .msg à déposer ici.
Thunderbird
Clic droit sur le mail, « Transférer au format » › « Pièce jointe ». Ou « Fichier » › « Enregistrer comme » › « Fichier » pour obtenir un .eml.
Apple Mail (Mac)
Sélectionnez le mail, menu « Message » › « Transférer en tant que pièce jointe ». Ou faites-le glisser sur le bureau pour obtenir un .eml.
Toutes les messageries de bureau
Glisser le mail depuis la liste vers une nouvelle fenêtre de rédaction l'ajoute en général comme pièce jointe.
